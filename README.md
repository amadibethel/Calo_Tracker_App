# NutriTrack - Calorie & Macro Tracker

NutriTrack is a pure vanilla JavaScript calorie and macronutrient tracking web application. Built with zero external dependencies and zero frameworks, utilizing browser-native `localStorage` for privacy and persistence.

## Features

- **Daily Calorie & Macro Tracking**: Monitor calories, protein, carbs, and fats against customizable daily goals.
- **Visual Progress**: Real-time circular progress rings and macro breakdown bars.
- **Meal Breakdown**: Categorize items into Breakfast, Lunch, Dinner, and Snacks.
- **Curated Food Presets**: Fast logging from a pre-populated list of common foods.
- **Water Intake Tracker**: Track hydration glasses throughout the day.
- **Local Persistence**: All data remains securely stored in the user's browser.

## Getting Started

Simply open `index.html` in any modern web browser or serve it via a static file server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve
```
